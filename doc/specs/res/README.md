Covers the full resource lifecycle: owner keys, ResourceIndex, the `nexus reap` command, journaled create, recover reconciliation, and extreme-case leak testing.

Charter trace prefix: `REQ-RES-*` maps to spec nodes `RES-R-001` … `RES-R-013`.
